X Bookmark Vault for Claude Code

Make something from your bookmarks

Start with your 20 most recent saves. Claude will suggest what you can make and save the one you choose to your Mac.

  1. In Chrome, install Claude in Chrome and sign in to X in the same Chrome profile.
  2. Start Claude Code with Chrome access: run claude --chrome in Terminal, or use the Code tab of the Claude desktop app with Claude in Chrome connected.
  3. Copy the prompt, paste it into Claude Code, and send it. Allow x.com when Claude in Chrome asks.

Pick a number after Claude shows your choices. Your finished Markdown file will be in the vault’s answers folder.
